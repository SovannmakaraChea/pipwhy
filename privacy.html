Privacy Policy

Last updated: 30 October 2026

The Pip Why app is a personal posting tool run by Makara (Chea Sovannmakara) on his own computer. It is used only with the Pip Why accounts he owns on YouTube, TikTok, Facebook and Instagram. This page explains what it handles.

What the app accesses

  • Basic information of the connected account (for example the YouTube channel name and ID) to confirm the right account is connected.
  • Permission to upload and publish videos to that account.
  • Statistics of the videos it posted (views, likes, comments, shares) for a weekly report to the owner.

What the app does not do

  • It does not collect data from other people, followers or viewers.
  • It does not sell, share or transfer any data to third parties.
  • It does not use any data for advertising or profiling.

YouTube API Services

The app uses YouTube API Services to upload videos and read video statistics. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Storage

Access tokens are stored only on the owner's computer, in a local file that is never published or shared. Post records (video name, date, post ID and link) are kept in the same local folder. Nothing is stored on a server.

Removing access

Access can be removed at any time from each platform's settings (for example Google: myaccount.google.com/permissions; TikTok: Settings and privacy > Security > Apps and services). Removing access stops the app from posting. Local tokens are deleted when access is removed.
